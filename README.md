# Recovery Safety Net MVP

A web-based safety net for students and creators using AI code generators.
Save a checkpoint before prompting AI, and restore in one clear action if an edit causes a regression.

- 📄 **Compiled Submission PDF:** [Recovery_MVP_Submission.pdf](Recovery_MVP_Submission.pdf)

## Scope & Must-Haves
- **M-1:** Save recovery point before an AI change
- **M-2:** List recent recovery points with time and short label
- **M-3:** Restore selected recovery point in one clear action

Built with pure Vanilla HTML5, Tailwind CSS, and Modern JavaScript. Zero build-step required.
